# synergy-practice
# Решения практических кейсов № 3 и № 4

Репозиторий содержит две программы на Python 3.

## Кейс № 3 — сумма отрицательных элементов

Файл: `case3_array.py`

Программа получает массив целых чисел, находит первое вхождение максимального и минимального элементов, а затем вычисляет сумму отрицательных элементов, расположенных строго между ними.

Сами максимальный и минимальный элементы в сумму не включаются.

Примеры:
- `-3 8 -2 5 -7 1` → `-2`
- `9 -4 2 -6 1` → `-4`
- `1 2 3 4` → `0`

## Кейс № 4 — максимальное произведение голов драконов

Файл: `case4_dragons.py`

Программа разбивает заданное количество голов N на положительные части от 1 до 7 так, чтобы произведение этих частей было максимальным.

Используется метод динамического программирования.

Массив dp хранит максимальное произведение для каждого значения суммы. Массив choice используется для восстановления найденного разбиения.

Примеры:
- N = 4 → [2, 2], произведение 4
- N = 7 → [3, 4], произведение 12
- N = 10 → [3, 3, 4], произведение 36
- N = 20 → [2, 3, 3, 3, 3, 3, 3], произведение 1458

## Запуск программ

Требуется Python 3.

Запуск кейса № 3:
python3 case3_array.py

Запуск кейса № 4:
python3 case4_dragons.py

Сложность алгоритма кейса № 4:
Время — O(7N), память — O(N).
